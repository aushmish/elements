# Flowly Email Template

A premium SaaS product announcement email built using
@unlayer/react-elements.

## Features

- Responsive marketing email
- Hero section
- Feature cards
- CTA sections
- Reusable component architecture

## Tech

- React
- TypeScript
- @unlayer/react-elements
- Vite

## Run

pnpm install

pnpm build

pnpm --filter @unlayer/elements-demo dev
